# autolavado24h
Integrantes: Juan Pablo Jimenez  – Isabella Pelaez
1. Descripción de la aplicación
Autolavado 24H es un autolavado híbrido de carros y motos que funciona las 24 horas: el cliente puede lavar él mismo su vehículo en autoservicio o pedir un lavado manual hecho por un operario. La aplicación es el sistema con el que el autolavado registra cada lavado y consulta la información del negocio.
Los usuarios escriben datos en la base de datos al registrar clientes, vehículos y lavados, y extraen datos al consultar historiales e indicadores:

2. Arquitectura en estrella
LAVADO es la tabla de hechos: registra el evento del negocio un lavado y sus medidas numéricas (valor bruto, descuento, valor total, calificación y duración). CLIENTE, VEHICULO y SERVICIO son las dimensiones: describen quién pidió el servicio, a qué vehículo se le hizo y qué servicio fue.
•	Grano: una fila de LAVADO es un servicio realizado a un vehículo de un cliente en una visita. Si en una visita se hace lavado integral y polichado, quedan dos filas.
•	Solo hechos dimensión: cada dimensión se conecta únicamente con LAVADO (relación 1 : 0..N) y no entre sí. Por eso VEHICULO no tiene llave hacia CLIENTE; además, un mismo carro puede llevarlo el dueño, un familiar o el conductor de una empresa.
•	Historia de precios: LAVADO guarda el valor cobrado aunque SERVICIO tenga un precio de lista, porque el precio del catálogo puede cambiar y el hecho debe conservar lo que realmente se pagó.
•	Sin borrados en cascada: clientes y servicios no se eliminan; se marcan como INACTIVO para no perder el historial de lavados.
